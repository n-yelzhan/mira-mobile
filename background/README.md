# Background Information

This folder describes the world in which all cases take place. It does not belong to any single case: every case uses the same country, market, company and data systems.

Read these documents before opening a case.

## Documents

| File | What it covers |
|---|---|
| `01_country.md` | Mediland: geography, regions, population, economy. |
| `02_telecom_market.md` | The telecom market: operators, market shares, regulation, trends. |
| `03_mira_mobile.md` | Mira Mobile: history, products, customers, organisation. |
| `04_data_architecture.md` | Mira Mobile's source systems (CRM, Billing, etc.), their tables and how they connect. |
| `05_accounting_policy.md` | Company rules for counting customers, revenue and other metrics. All cases follow these rules. |

_Documents will be added step by step._
