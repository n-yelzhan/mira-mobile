# Mira Mobile — Telecom Analytics Cases

A collection of telecom analytics case studies for **Mira Mobile**, a fictional mobile operator in **Mediland**, a fictional country with its own economy and telecom market.

Each case starts with a business problem and walks through the full path: data collection from several source systems, data quality checks, analysis, modelling and a final result for the business.

> **Disclaimer**
> Mediland, Mira Mobile and all other companies, people, places and events in this repository are fictional.
> All data is synthetic and was generated for learning purposes only. It does not come from any real company.
> Any resemblance to real countries, companies or people is coincidental.

## Repository structure

| Folder | What is inside |
|---|---|
| [`background/`](background/) | **Background information**: the country, the telecom market, the company, its data systems and accounting policy. Read this first. |
| [`universe_data/`](universe_data/) | Reference data shared by all cases: tariffs, services, bundles, content partners. |
| [`mediland/`](mediland/) | Shared Python code used by more than one case. |
| [`cases/`](cases/) | Case studies. Each business problem lives in its own folder. |

## How to read this repository

1. Start with [`background/`](background/) to understand the world and the company.
2. Pick a case in [`cases/`](cases/). Each case has its own README with the business problem, approach and results.
