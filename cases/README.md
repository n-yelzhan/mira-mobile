# Cases

Each case is one business problem of Mira Mobile, solved from start to finish. Every case has its own folder.

## Suggested structure of a case folder

```
cases/NN_case_name/
├── README.md     # business problem, hypotheses, approach, results
├── data/         # case data: raw (from source systems) and processed
├── notebooks/    # analysis step by step
├── src/          # case code: data preparation, features, models
└── docs/         # documentation, presentation, posts
```

Some cases may add more folders (for example `api/` or `dashboard/`) if they need them.
